# 📄 Templater Plugin Setup Guide

This vault includes preconfigured standard templates in `Templates/` for rapid note creation and strict adherence to [[.agent/schema|YAML Schemas]].

---

## 🛠️ Configuration Steps in Obsidian:

1. Open **Settings > Community Plugins**.
2. Search for **Templater** and click **Install**, then **Enable**.
3. Under **Templater Settings**:
   - Set **Template folder location** to: `Templates`
   - Enable **Trigger Templater on new file creation** (optional).
   - Set **Syntax highlight** to `Enabled`.
4. Hotkeys recommendation:
   - Assign `Alt + N` or `Ctrl + Shift + T` to **Templater: Open Insert Template modal**.
